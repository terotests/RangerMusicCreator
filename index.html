Ranger Music Creator

Press PLAY (or a style button) and it composes forever: intros, builds, drops and breakdowns, new melodies, key changes and echo throws, all from rules and a random seed. No samples and no AI model: every sound is synthesised in your browser, so what you record is yours to use, free of royalties (see LICENSES.md).

  • STYLE SWITCHER 1–8 picks the style; it changes at the next bar. JOURNEY lets it wander between styles by itself.
  • NEXT jumps to the next section now. BREAK, BUILD, HALF-TIME, FILTER and ECHO THROW remix it live. FREEZE loops the current section.
  • SURPRISE sets how often it changes things on you.
  • AMBIENCE pads add rain, wind, ocean, birds, night, fire, vinyl and city. AUTO lets each style choose.
  • Mixer: SEND is echo + reverb, NEW rewrites that part, faders move by themselves while AUTO MIXING is lit (touch one and it is yours for a while).
  • SESSION TAPE (bottom) keeps the last 10 minutes. Click a section or drag over a stretch, then LISTEN to hear it again, SAVE WAV to export it, or GO BACK to continue the music from that section and remix it differently. ★ bookmarks the moment.
  • LOOP repeats the last four bars exactly, so a good moment does not get away. STORE puts it in a THEME MEMORY slot; clicking a slot makes it the song's base theme and the composer only plays variations around it (THEME LOCK). Shift-click clears a slot.
  • Under each fader: ♻ NEW writes a new part, HOLD keeps the part as it is.
  • SAVE SET / LOAD SET keep the whole session (song state, mix, instruments, theme memory) in a small file. MIDI OUT exports the tape (or the selection) as MIDI, one track per part. MIDI IN takes the melody of a MIDI file and makes it the theme.
  • The instrument name under each channel is a button: click it to change the sound (shift-click goes back, AUTO follows the style).
  • REC records to a WAV file for as long as you like. LINK copies a link with the seed and style.
  • Keys: space play/pause, 1–8 styles, N next, L loop, F freeze, E echo throw, B break, M bookmark, R new song.
